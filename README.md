# 🗺️ 우리 데이트 맵

카카오 지도 기반 커플 데이트 장소 공유 앱

## 사용법

### 로컬에서 열기
`date-map.html` 파일을 브라우저에서 바로 열면 됩니다.

### GitHub Pages로 배포 (권장)
1. GitHub 레포 생성
2. `date-map.html` 업로드
3. Settings → Pages → Branch: main 활성화
4. [카카오 개발자 콘솔](https://developers.kakao.com) → 앱 → 플랫폼 키 → Web → 생성된 주소 등록
5. 배포된 주소로 접속

## 기능

- 📍 **장소 추가** — 카카오 장소 검색 또는 직접 입력
- 🗂 **카테고리 관리** — 이름/이모지/색상 커스텀
- 🗺 **지도 연동** — 카카오 지도에 핀 표시
- ✅ **방문 체크** — 다녀온 곳 체크 관리
- 🔗 **공유** — 코드 복사/붙여넣기로 서로 장소 동기화

## 공유 방법

1. **설정/공유 탭** → 코드 복사
2. 카카오톡으로 상대방에게 전송
3. 상대방이 불러오기에 붙여넣기 → 장소 합쳐짐

## 카카오 API 키

`date-map.html` 파일 내 아래 두 곳에 본인 키 입력:
```
appkey=YOUR_JAVASCRIPT_KEY   (지도 SDK)
KakaoAK YOUR_REST_KEY        (장소 검색)
```
